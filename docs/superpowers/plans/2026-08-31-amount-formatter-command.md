# Amount Formatter Command Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `gold_flutter add amount-formatter` to install a configurable `intl`-based money formatter and focused tests into an existing Flutter project.

**Architecture:** Interactive or flag-based answers form an immutable formatter configuration. A deterministic template renderer creates owned Dart source and test files, while the shared transaction snapshots dependency files, runs `flutter pub add intl`, writes files, and verifies them.

**Tech Stack:** Dart 3.5+, `args`, Flutter, `intl`, shared Developer Assistant Core

**Spec:** `docs/superpowers/specs/2026-08-31-developer-assistant-design.md`

## Global Constraints

- Complete `2026-08-31-developer-assistant-core.md` first.
- Default locale is exactly `en_NG`, symbol `₦`, decimal digits `2`, grouping enabled, and hidden text `₦ •••••`.
- Do not overwrite unowned formatter or test files.
- Snapshot `pubspec.yaml` and `pubspec.lock` before dependency changes.
- A failed format, analysis, or focused test restores owned project files.
- Internet use through normal Flutter dependency resolution is allowed.

## File map

- Create `lib/src/amount/amount_formatter_answers.dart`: validated configuration.
- Create `lib/src/amount/amount_formatter_answers_collector.dart`: terminal prompts.
- Create `lib/src/amount/amount_formatter_renderer.dart`: owned source and test templates.
- Create `lib/src/amount/amount_formatter_installer.dart`: plan construction.
- Create unit tests under `test/unit/amount/`.
- Modify CLI and README.

- [ ] **Step 2: Run and observe failure**

- [ ] **Step 3: Implement the renderer**

`NumberFormat.currency` with the configured locale, symbol, and decimal digits.
For grouping disabled, format normally then remove the locale's grouping
separator obtained from `NumberFormat.decimalPattern(locale).symbols.GROUP_SEP`.

Generated test expectations for defaults are:

```dart

expect(MoneyFormatter.format(12.5), '₦12.50');
expect(MoneyFormatter.format(1200), '₦1,200.00');
expect(MoneyFormatter.format(1200, showDecimals: false), '₦1,200');
expect(MoneyFormatter.hidden(), '₦ •••••');
```

- [ ] **Step 4: Cover quotes, dollar signs, and backslashes**

Render a symbol containing `$` and hidden text containing an apostrophe;
parse the result with analyzer and assert no syntax errors.

# Gold Flutter Instructions

## Mandatory development skill

For every task that creates, changes, refactors, debugs, tests, profiles, or
reviews Gold Flutter's Dart generator, Flutter templates, or generated project
instructions, load and follow `$gold-flutter-development` from
`.agents/skills/gold-flutter-development/SKILL.md` before inspecting or editing
that code.

## Scope

- Keep the generator's actual templates and focused tests in sync.
- Preserve the architecture and UI conventions promised to generated apps.
- Treat generated `AGENTS.md` and project skill files as AI instructions for
  people using Gold Flutter after project setup.
- Run verification proportional to the files changed and report checks that
  could not run.
